# Contributing

1. Open an issue describing the image source, expected behaviour and a minimal anonymised example.
2. Create a focused branch and add or update tests.
3. Run `python -m unittest discover -s tests -v` before submitting a pull request.
4. Do not commit RAW photographs, XMP sidecars, material labels, unpublished phenotype tables or other sensitive data.
5. State whether a proposed algorithm change alters colour conversion, segmentation, aggregation or statistical inference. Such changes require a versioned configuration and a reproducibility note.

By contributing, you agree that your contribution is licensed under Apache-2.0.
